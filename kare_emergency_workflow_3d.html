Python Backend Architecture
FastAPI (or Django REST) handles routing, auth, and business logic. Emergency cases bypass normal queues via a priority Celery lane, triggering multi-channel alerts within 30 seconds of submission.
# ── Kare Emergency Dispatch — FastAPI + Celery ── from fastapi import APIRouter, Depends, HTTPException from celery import Celery from .models import EmergencyCase from .ai_triage import score_severity from .notifications import dispatch_va, send_sms, push_alert router = APIRouter(prefix="/api/emergency") celery = Celery("kare", broker="redis://localhost:6379/0") @router.post("/dispatch") async def emergency_dispatch( payload: EmergencyCase, user = Depends(get_current_user) ): # 1. AI triage — severity 1-5 severity = await score_severity(payload.description) # 2. Persist to PostgreSQL case = await Case.create( user_id=user.id, severity=severity, status="URGENT" ) # 3. Fire async tasks (priority queue) if severity >= 4: dispatch_va.apply_async( args=[case.id], queue="emergency", # bypasses normal queue countdown=0 ) send_sms.delay(user.phone, case.id) push_alert.delay(case.id) return {"case_id": case.id, "severity": severity, "eta_seconds": 30} # AI Triage model async def score_severity(text: str) -> int: """NLP model returns 1-5 urgency score""" tokens = tokenize(text) logits = model.predict(tokens) return int(logits.argmax()) + 1
Backend Flow Explanation
1. Route guard — JWT auth middleware validates every request before it hits any handler.
2. AI triage — BERT-based NLP model scores case description severity (1–5) in <200ms.
3. Priority queue — Celery + Redis separates emergency from normal task lanes.
4. PostgreSQL — Cases, audit logs, and VA assignments stored with full history.
5. Notifications — Twilio SMS + Firebase push + email dispatched in parallel via async tasks.
6. WebSocket push — Django Channels broadcasts live VA ETA back to the frontend.
